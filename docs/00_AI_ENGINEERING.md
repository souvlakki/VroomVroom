# AI Engineering

## Read First
Every AI agent must read this document before making changes.

## Rules
- Never delete working code without approval.
- Make the smallest safe change.
- Preserve existing functionality.
- Run the build after every change.
- Update documentation as part of every feature.
- Never modify production Supabase settings without approval.
- Present a summary before committing.

## Standard Workflow
1. Read documentation.
2. Understand the task.
3. Produce a plan.
4. Implement.
5. Build.
6. Fix build issues.
7. Update docs.
8. Request approval.
9. Commit.
